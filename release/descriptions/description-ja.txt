C:V — よく使う定型文をショートカットキーですばやくコピー。

同じ文章を何度も入力したり、コピーしたい文章を探してタブを行き来したりしていませんか？
よく使うあいさつや返信、メールのひな形を C:V に保存しておきましょう。
必要なときに数字キーのショートカットでコピーして、好きな場所に貼り付けられます。

■ C:V でできること

• 10個のリストに10件ずつ、合計100件まで定型文を保存できます。
• 仕事や用途に合わせて、定型文をリストに分けて管理できます。
• ウェブページで選択した文章をショートカットキーで保存できます。
• ポップアップを開かずに、保存した定型文をコピーできます。
• リストや定型文はドラッグ＆ドロップで並べ替えられます。
• アカウント登録は不要です。定型文は使用中の Chrome プロフィールに保存され、外部サーバーには送信されません。

■ はじめかた

1. Chrome のツールバーにある C:V のアイコンをクリックし、ポップアップを開きます。
2. 「リストを管理」からリストを作成し、使用するリストを選びます。
3. 画面下部の「＋ 追加」を押して、よく使う文章を保存します。
4. ウェブページで Shift キーと数字キーを押し、リストを選びます。
5. Alt キーと数字キーを押して定型文をコピーし、貼り付けたい場所で Ctrl + V（Mac では Command + V）を押します。

定型文の編集や削除は、各項目のメニュー（⋯）から行えます。

■ ショートカットキー一覧

• リストを選択：Shift + 数字キー
• 保存した定型文をコピー：Alt + 数字キー
• ウェブページで選択した文章を保存：Shift + Alt + 数字キー
• 貼り付け：Ctrl + V（Mac では Command + V）
• ポップアップを開く：Ctrl + B（Mac では Command + B）

※ Mac でインストール直後に Command + B が反応しない場合は、Chrome のアドレスバーに chrome://extensions/shortcuts と入力し、C:V のポップアップを開くショートカットキーに Command + B をもう一度設定してください。

Mac では Alt キーの代わりに Option キーを使います。
数字キーの 1〜9 はそれぞれ1〜9番に対応し、0 は10番に対応します。

たとえば、最初のリストを作成したら、ウェブページで Shift + 1 を押して選択します。
保存したい文章をドラッグして選び、Shift + Alt + 1 を押すと1番に保存できます。
あとで Alt + 1 を押せば、同じ文章をもう一度コピーできます。

※ リストの選択と定型文のコピーは、入力欄やエディターの外で行ってください。貼り付けるときは入力欄をクリックし、Ctrl + V（Mac では Command + V）を押してください。
※ Chrome の設定ページなど、拡張機能が動作しないページではウェブページ用のショートカットキーは使えません。キーの組み合わせが重複する場合は、Chrome の拡張機能のショートカット設定で、ポップアップを開くキーを確認してください。

⚠ ご利用前にご確認ください

• 個人情報、パスワード、認証コード、API キーなどの機密情報は保存しないでください。C:V は機密情報の保管を目的としたツールではありません。
• 定型文が入っている番号に新しい文章を保存すると、元の内容が上書きされます。保存前に、選択したリストと番号を確認してください。
• 拡張機能をアンインストールしたり、拡張機能のデータや Chrome プロフィールを削除したりすると、保存した定型文が消えることがあります。バックアップや復元の機能はないため、大切な文章は別の場所にも保存してください。
• 旧バージョンからアップデートする場合、保存済みの定型文は自動で引き継がれません。必要な定型文はアップデート前に別の場所へ保存してください。
