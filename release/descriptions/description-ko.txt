C:V — 자주 쓰는 문장, 단축키로 바로 복사하세요.

매번 같은 문장을 다시 입력하거나, 복사할 내용을 찾아 여러 탭을 오가고 있나요?
인사말, 반복 답변, 이메일 양식처럼 자주 쓰는 문장을 C:V에 저장해 보세요.
필요할 때 숫자 단축키로 복사하고, 원하는 곳에 붙여넣으면 돼요!

■ C:V로 할 수 있어요

• 최대 10개의 리스트에 문장을 10개씩, 총 100개까지 저장할 수 있어요.
• 업무별·상황별로 리스트를 나눠 문장을 관리할 수 있어요.
• 웹페이지에서 선택한 텍스트를 단축키로 바로 저장할 수 있어요.
• 저장한 문장은 팝업을 열지 않고 단축키로 복사할 수 있어요.
• 리스트와 문장의 순서는 드래그 앤 드롭으로 바꿀 수 있어요.
• 계정 없이 사용할 수 있고, 저장한 내용은 사용 중인 Chrome 프로필에 보관돼요. 외부 서버로 전송하지 않아요.

■ 처음이라면 이렇게 시작해 보세요

1. Chrome 도구 모음에서 C:V 아이콘을 눌러 팝업을 열어 주세요.
2. ‘리스트 관리’에서 리스트를 만들고, 사용할 리스트를 선택해 주세요.
3. 아래쪽 ‘+ 추가’ 버튼으로 자주 쓰는 문장을 저장해 주세요.
4. 웹페이지에서 Shift + 숫자로 리스트를 선택해 주세요.
5. Alt + 숫자로 원하는 문장을 복사한 뒤, 입력할 곳에서 Ctrl 또는 Command + V로 붙여넣으세요.

문장을 수정하거나 삭제하려면 각 항목의 더보기 메뉴(⋯)를 이용해 주세요.

■ 단축키 한눈에 보기

• 리스트 선택: Shift + 숫자
• 저장된 문장 복사: Alt + 숫자
• 웹페이지에서 선택한 텍스트 저장: Shift + Alt + 숫자
• 붙여넣기: Ctrl + V / Mac은 Command + V
• 팝업 열기: Ctrl + B / Mac은 Command + B

Mac에서는 Alt 대신 Option 키를 사용해 주세요.
숫자 1~9는 1~9번, 숫자 0은 10번이에요.

예를 들어, 첫 번째 리스트를 만든 뒤 웹페이지에서 Shift + 1을 눌러 선택해 보세요.
저장할 텍스트를 드래그해 선택하고 Shift + Alt + 1을 누르면 첫 번째 문장으로 저장돼요.
나중에 Alt + 1을 누르면 그 문장을 다시 복사할 수 있어요.

※ 리스트 선택과 문장 복사는 입력창 밖에서 실행해 주세요. 붙여넣을 때는 원하는 입력창을 클릭한 뒤 Ctrl 또는 Command + V를 눌러 주세요.
※ Chrome 설정 페이지 등 확장프로그램이 실행될 수 없는 페이지에서는 웹페이지 단축키를 사용할 수 없어요. 단축키가 겹치면 Chrome의 확장프로그램 단축키 설정에서 팝업 단축키를 확인해 주세요.

⚠ 꼭 확인해 주세요

• 개인정보, 비밀번호, 인증번호, API 키 등 민감한 정보는 저장하지 마세요. C:V는 보안 정보 보관용 도구가 아니에요.
• 이미 문장이 저장된 번호에 새 텍스트를 저장하면 기존 내용이 바뀌어요. 저장 전에 리스트와 번호를 확인해 주세요.
• 확장프로그램을 제거하거나 확장프로그램 데이터 또는 Chrome 프로필을 삭제하면 저장한 내용도 삭제될 수 있어요. 별도의 백업·복구 기능이 없으니 중요한 내용은 다른 곳에도 보관해 주세요.
• 구버전에서 업데이트하는 경우 기존 저장 내용은 자동으로 이전되지 않아요. 업데이트 전에 필요한 문장을 별도로 보관해 주세요.
