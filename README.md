# C:V

C:V는 자주 쓰는 문장을 리스트별로 보관하고, 숫자 단축키로 리스트의 슬롯에 복사하는 Chrome 데스크톱 확장 프로그램입니다. 반복 답변, 이메일 양식, 블로그 문구를 다시 찾아 복사하는 일을 줄입니다.

최대 10개 리스트에 문장을 10개씩 저장합니다. 계정·외부 서버·기기 간 동기화 없이 Chrome 프로필 안에 보관하며, 복사한 문장은 사용자가 직접 붙여넣습니다.

## 처음 사용하는 순서

1. C:V 팝업에서 리스트를 만들고 현재 리스트로 선택합니다.
2. 아래쪽 추가 버튼으로 문장을 저장합니다.
3. 입력창에 커서를 둔 채 Windows에서 `Ctrl+왼쪽 Alt+1`, Mac에서 `Control+Option+1`로 첫 문장을 선택하고 클립보드에 복사합니다.
4. 복사 알림이 뜨면 Windows에서 `Ctrl+V`, Mac에서 `Command+V`로 붙여넣습니다. 슬롯에 복사하려면 Windows에서 `왼쪽 Alt+2`, Mac에서 `Control+2`를 누릅니다.

`Ctrl+Shift+숫자`로 현재 리스트를 바꿉니다. 위쪽 숫자 키의 `0`은 10번입니다. 기존 슬롯에 복사하면 내용을 교체합니다. 팝업의 문장 메뉴에서도 **클립보드에 복사**할 수 있습니다.

## 개발 환경에서 실행하기

Node.js 24 계열과 npm을 사용합니다. 저장소 루트에서 실행합니다.

```sh
npm ci
npm run build
```

타입 검사 후 팝업·background·content script를 `dist/`에 생성합니다. Chrome의 `chrome://extensions`에서 개발자 모드를 켜고 **압축 해제된 확장 프로그램을 로드**를 눌러 `dist/`를 선택합니다.

```sh
npm run dev
```

개발 서버 주소의 `/design/wireframes/`에서는 정적 디자인 보드를 볼 수 있습니다. 실제 저장·복사 검증은 Chrome에 설치한 확장에서 진행합니다.

## 구현과 검증 상태

2026-10-25 확인한 `main` 기준 소스에는 React 팝업, 리스트·문장 관리, 로컬 저장, 웹 단축키와 알림이 구현돼 있습니다. 기능은 현재 소스로 빌드할 수 있습니다. 과거 브랜치의 초기 시작 화면과 혼동하지 않도록 체크아웃한 브랜치를 확인하세요.

기존 QA 기록에는 macOS Chrome의 핵심 흐름과 접근성 점검 결과가 있습니다. OS 모션 감소·스크린 리더 음성·Windows/Linux 실기기 검증은 남아 있습니다. 기록된 검증과 이번 문서 검토의 확인 범위는 [QA 절차](docs/qa.md)와 [개발 안내](docs/development.md)에 구분했습니다. 스토어 제출·공개 배포 완료를 뜻하지 않습니다.

C:V는 자체 암호화·백업·복구 기능이 없습니다. 민감한 정보는 저장하지 마세요. 이전 JavaScript 버전의 IndexedDB 데이터도 자동으로 이전하지 않습니다.
