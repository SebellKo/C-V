# C:V 프로젝트 문서

## 프로젝트 개요

`C:V`는 크롬 확장 프로그램 기반의 멀티 복사/붙여넣기 도구입니다.
사용자는 문장이나 템플릿을 여러 개의 리스트와 슬롯에 저장해 두고, 단축키로 빠르게 선택하고 붙여넣을 수 있습니다.

이 저장소는 확장 프로그램의 두 축을 함께 포함합니다.

- 팝업 UI: 리스트와 커맨드를 추가, 수정, 삭제, 정렬하는 관리 화면
- 확장 실행 로직: 웹 페이지에서 단축키를 감지하고 IndexedDB에 저장된 데이터를 읽고 쓰는 서비스 워커와 콘텐츠 스크립트

## 어떤 문제를 해결하는가

반복적으로 사용하는 문장, 템플릿, 답변, 메모를 여러 탭과 문서 사이에서 복사해 가며 작업하는 비효율을 줄이는 것이 목적입니다.
사용자는 자주 쓰는 문구를 리스트 단위로 정리하고, 숫자 키 조합으로 원하는 슬롯을 바로 선택할 수 있습니다.

## 핵심 기능

### 1. 리스트 관리

- 리스트 생성
- 리스트 이름 수정
- 리스트 순서 변경
- 리스트 삭제
- 현재 사용할 리스트 선택

구현 기준 제약:

- 리스트는 최대 10개까지 생성 가능
- 리스트 이름 중복은 허용되지 않음

### 2. 커맨드 관리

- 선택한 리스트에 커맨드 추가
- 커맨드 내용 수정
- 개별 커맨드 삭제
- 리스트 내 커맨드 전체 삭제
- 드래그 앤 드롭으로 커맨드 순서 변경

구현 기준 제약:

- 리스트당 커맨드는 최대 10개까지 저장 가능
- 동일 리스트 안에서 중복 커맨드는 허용되지 않음

### 3. 단축키 기반 멀티 복사/붙여넣기

README와 콘텐츠 스크립트 기준으로 다음 흐름을 제공합니다.

- `Shift + 0~9`: 현재 리스트 선택
- `Alt + 0~9`: 현재 리스트의 특정 커맨드 선택
- `Shift + Alt + 0~9`: 현재 선택한 텍스트를 해당 슬롯에 저장
- `Ctrl + B` / `Command + B`: 확장 팝업 열기

숫자 `0`은 10번째 슬롯으로 취급됩니다.

### 4. 데이터 영속성

- 리스트와 커맨드 데이터는 `IndexedDB`에 저장됨
- 현재 선택된 리스트도 별도 저장소에 유지됨
- 브라우저 데이터 삭제 시 저장 데이터가 함께 사라질 수 있음

## 사용자 관점 동작 흐름

1. 팝업에서 리스트를 만든다.
2. 팝업에서 리스트를 선택한다.
3. 웹 페이지에서 텍스트를 드래그해 선택한다.
4. `Shift + Alt + 숫자`로 선택한 텍스트를 특정 슬롯에 저장한다.
5. `Alt + 숫자`로 원하는 커맨드를 클립보드에 올린다.
6. 원하는 입력 위치에서 일반 붙여넣기를 수행한다.

## 아키텍처 요약

이 프로젝트는 Manifest V3 기반 크롬 확장 프로그램입니다.

### 1. 팝업 UI 레이어

`src/` 아래의 React 앱이 확장 프로그램 팝업 화면을 담당합니다.

- 헤더: 리스트 선택, 리스트 추가/편집 진입
- 메인: 커맨드 목록, 신규 커맨드 추가, 수정 모달
- 푸터: 현재 리스트의 커맨드 전체 삭제

상태 관리 방식:

- `zustand`: 현재 선택 리스트, 선택된 커맨드, 모달 열림 상태 관리
- `@tanstack/react-query`: 서비스 워커 메시지 기반 조회/변경과 캐시 무효화 처리

### 2. 브라우저 확장 실행 레이어

`public/` 아래에 확장 프로그램 실행 파일이 있습니다.

- `manifest.json`: 확장 메타데이터와 팝업/콘텐츠 스크립트/서비스 워커 등록
- `service-worker.js`: 메시지 라우팅과 데이터 처리 진입점
- `contents/*.js`: 웹 페이지의 키 입력과 선택 텍스트를 감지하는 콘텐츠 스크립트
- `modules/service/*.js`: 리스트/커맨드 CRUD와 현재 리스트 저장 로직

### 3. 저장소 레이어

`IndexedDB`의 `CVStore` 데이터베이스를 사용합니다.

- `list` 스토어: 리스트 이름과 커맨드 배열 저장
- `currentList` 스토어: 현재 선택한 리스트 이름 저장

## 기술 스택

- React 18
- JavaScript
- Create React App (`react-scripts`)
- Zustand
- TanStack Query
- styled-components
- dnd-kit
- Chrome Extension Manifest V3
- IndexedDB

## 주요 디렉토리

```text
src/
  api/                팝업 UI에서 서비스 워커로 메시지를 보내는 API 래퍼
  components/         팝업 UI 컴포넌트
  hooks/              React Query 기반 조회/변경 훅
  stores/             Zustand 스토어
  styles/             styled-components 기반 공용 스타일

public/
  manifest.json       크롬 확장 설정
  service-worker.js   백그라운드 메시지 처리
  contents/           단축키/선택 텍스트 감지
  modules/            IndexedDB 접근 및 서비스 함수
```

## 현재 코드 기준으로 이해해야 할 점

- 이 저장소는 일반 웹앱이 아니라 "팝업 UI를 가진 크롬 확장 프로그램"입니다.
- 팝업 UI와 확장 실행 로직이 하나의 저장소 안에 함께 들어 있습니다.
- 실제 복사/붙여넣기 경험의 핵심은 콘텐츠 스크립트와 서비스 워커에 있고, `src/`는 그 설정과 데이터를 관리하는 관리자 화면 역할이 더 큽니다.
- 테스트 코드나 배포 문서는 현재 저장소에서 확인되지 않았습니다.

## 한 줄 요약

`C:V`는 리스트와 슬롯 단위로 문구를 저장하고, 단축키로 빠르게 복사/선택/붙여넣기할 수 있게 만든 크롬 확장 프로그램입니다.
