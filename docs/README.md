# C:V 문서 안내

이 문서 묶음은 코드를 열기 전에 제품의 목적, 사용 방법, 데이터 처리, 구현 상태를 파악하기 위한 안내입니다. 기준일은 **2026-10-25**이며, 최신 `main`의 기준 커밋 `605dfa4`를 확인했습니다.

## 먼저 알아둘 상태

현재 소스는 React 팝업, 리스트·문장 관리, 로컬 저장, 웹 단축키·클립보드 쓰기·알림을 구현합니다. `npm run build`로 설치 가능한 `dist/`를 만듭니다. 초기 골격만 있던 과거 아키텍처 브랜치와 구분해야 합니다.

| 표현 | 뜻 |
| --- | --- |
| 현재 구현 | 기준 커밋의 소스를 읽어 확인한 동작. 실제 브라우저 검증 여부와 별개입니다. |
| 디자인 보드 | 기능에 연결되지 않은 정적 화면 예시입니다. |
| 설계·검증 기준 | 유지해야 하는 규칙이나 추가 확인할 항목. 통과 기록을 뜻하지 않습니다. |
| 과거 검증 기록 | `docs/qa.md`의 날짜별 결과. 이번 문서 작업에서 다시 실행한 결과가 아닙니다. |

`release/icons/`, `release/promo/`, `release/screenshots/`, `release/descriptions/`는 Git에서 관리하는 스토어 자료입니다. 배포 ZIP과 로컬 QA 산출물은 따로 관리하며 `release/`에 기능 원본 소스가 있다고 가정하지 않습니다.

## AI 에이전트가 답할 때

- “현재 사용할 수 있나요?”에는 소스 구현 여부, 검증 기록, 공개 배포 여부를 구분해 답합니다.
- 제품 기능은 현재 구현을 기준으로 설명하고 미검증 조건은 별도로 밝힙니다.
- 문서에 없는 가격, 스토어 공개 주소, 활성 사용자 수, 운영 담당자, 출시일은 추측하지 않습니다. 이번 검토에서는 확인하지 못했습니다.
- 데이터 보존이나 출시 준비 상태를 테스트 없이 보장하지 않습니다.
- 사용자의 실행 문제는 설치한 확장 버전·빌드·체크아웃한 브랜치를 먼저 확인합니다.
- 문서로 답할 수 없는 구현 세부사항은 각 문서의 근거 파일을 확인합니다.

## 문서를 유지하는 방법

각 문서는 첫 부분에 대상과 현재 상태를 설명합니다. 중요한 제한은 필요한 위치에 짧게 반복하고, 상세 규칙은 담당 문서로 연결합니다. 예전의 ‘문서 간 링크와 요약 금지’ 원칙은 적용하지 않습니다.

| 바뀐 내용 | 함께 갱신할 문서 |
| --- | --- |
| 사용자 동작, 단축키, 개수 제한, 오류 안내 | 제품, 필요한 경우 디자인 |
| 저장 데이터, 권한, 외부 통신, 보존·삭제 | 아키텍처, 제품의 데이터 안내, 배포 안내 |
| 모듈, 메시지, 의존성, 저장 형식 | 아키텍처, 개발 안내 |
| 화면 구성, 토큰, 메뉴, 알림 | 디자인, 제품의 사용자 흐름 |
| 실행·설치·검증 절차 또는 구현 상태 | 개발 안내, 루트 README, 이 문서 |

문서를 바꿀 때는 근거 파일과 확인 날짜를 갱신하고, 링크와 실행 명령을 확인합니다. 과거 검증 기록은 당시 기록으로 보존하며 현재 검증 결과로 바꿔 쓰지 않습니다.

작성 방식은 [ISO 24495-1:2023](https://www.iso.org/standard/78907.html)의 독자 중심 쉬운 언어 원칙을 적용합니다. 독자가 필요한 내용을 찾고, 이해하고, 다음 행동에 사용할 수 있도록 질문 중심 제목, 익숙한 용어, 구체적인 예시를 사용합니다. 이 문서는 표준 인증이나 전문에 대한 적합성 심사 결과를 뜻하지 않습니다.
