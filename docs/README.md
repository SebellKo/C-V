# C:V 문서 안내

이 문서는 `docs/`에 있는 기준 문서의 목적과 범위를 설명하는 카탈로그입니다. 각 기준 문서는 다른 문서를 읽지 않아도 자신의 범위를 이해할 수 있도록 독립적으로 작성합니다.

## 문서 목록

| 문서 | 상태 | 설명 | 포함하지 않는 내용 |
| --- | --- | --- | --- |
| [제품 기획 및 범위](./product.md) | 기준 확정 | 사용자 문제, MVP 범위, 기능 규칙, 사용자 흐름, 예외 동작과 완료 조건 | framework, module 구조, 시각 token의 구체적인 값 |

## 문서 독립성 원칙

- 기준 문서는 다른 기준 문서를 전제로 설명하지 않습니다.
- 하나의 규칙은 해당 범위를 소유한 문서 한 곳에만 기록합니다.
- 다른 문서의 내용을 요약하거나 우선순위를 두어 중복을 해결하지 않습니다.
- 범위를 넘는 내용은 다른 문서를 참조하는 대신 현재 문서의 비범위로만 명시합니다.
- 문서 탐색을 위한 링크와 전체 문서 설명은 이 카탈로그에서만 관리합니다.

## 변경할 문서 선택

| 변경 내용 | 수정할 문서 |
| --- | --- |
| 사용자 동작, 기능 제한, 오류 처리와 완료 조건 | 제품 기획 및 범위 |
| 저장 데이터, 권한, 보존 기간, 개인정보와 보안 | 데이터 및 개인정보 정책 |
| 색상, typography, layout, 컴포넌트와 시각적 상태 | 디자인 시스템과 와이어프레임 |
| dependency, module, message, schema, 동시성과 테스트 구성 | 아키텍처 |

기존 JavaScript 구현은 `legacy-js-final` Git tag에 참고용으로 보존되어 있으며 기준 문서의 요구사항을 대체하지 않습니다.
