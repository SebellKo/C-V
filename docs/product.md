# 제품과 사용 흐름

- 확인일: 2026-10-25
- 대상: C:V Chrome 데스크톱 확장 프로그램
- 기준: `main`의 `605dfa4` 소스. 아래는 현재 구현의 사용 방법과 기능 규칙입니다. 코드 확인과 실제 브라우저 검증은 구분합니다.

## C:V는 무엇을 위한 제품인가요?

C:V는 자주 쓰는 문장을 번호가 있는 리스트에 저장하고, 웹 페이지에서 단축키로 클립보드에 복사하는 도구입니다. 이메일 답변, 블로그 문구, 반복 안내, 고정 양식을 다시 찾아 복사하는 일을 줄입니다.

예를 들어 ‘업무 답변’ 리스트의 1번에 인사말, 2번에 자료 전달 안내를 저장합니다. 페이지에서 이 리스트를 선택하고 2번 문장을 복사한 뒤, 이메일 입력창에서 붙여넣습니다.

대상 사용자는 여러 텍스트를 반복해서 쓰는 사람과 키보드 중심으로 작업하는 사람입니다. 계정, 서버, 네트워크 연결 없이 핵심 기능을 쓰는 것을 제품 원칙으로 삼습니다.

## 지금 어느 정도 구현되어 있나요?

현재 소스에는 팝업 관리, 로컬 저장, 숫자 단축키, 클립보드 쓰기와 알림이 구현돼 있습니다. `npm run build`로 `dist/`에 설치용 파일을 생성합니다. 정적 디자인 보드는 기능 화면과 별개이며 데이터와 연결되지 않습니다.

[QA 기록](qa.md)에는 macOS Chrome 핵심 흐름과 접근성 점검 결과가 있습니다. 영구 자동 회귀 테스트는 포함하지 않습니다. OS 모션 감소·스크린 리더 음성·Windows/Linux 검증은 남아 있으며, 이번 문서 작업에서는 실제 Chrome 흐름을 다시 실행하지 않았습니다. 공개 스토어 배포 여부, 출시일, 가격은 확인하지 못했습니다.

## 용어와 저장 단위

| 용어 | 뜻 |
| --- | --- |
| 문장 또는 command | 저장한 일반 텍스트 한 항목. 여러 줄짜리 양식도 포함합니다. 코드에서는 `Command`라고 부릅니다. |
| 리스트 | 문장을 묶는 그룹. 예: 업무 답변, 블로그 문구 |
| 현재 리스트 | 웹 단축키로 문장을 저장하거나 복사할 대상. 선택이 없을 수도 있습니다. |
| 위치 | 리스트 또는 문장의 표시 순서. 1~10번이며 단축키와 연결됩니다. |
| 팝업 | Chrome 도구 모음의 C:V 아이콘으로 여는 관리 화면 |
| 웹 알림 또는 toast | 단축키 결과를 페이지 아래쪽에 잠시 표시하는 안내 |
| 초안 | 팝업에서 편집 중이며 아직 저장하지 않은 입력 |

리스트와 문장은 고유 ID로 식별합니다. 이름이나 위치가 바뀌어도 같은 항목입니다. 번호는 저장 순서에서 계산하므로 순서를 바꾸면 단축키로 불러오는 내용도 달라집니다.

## 할 수 있는 일과 범위

현재 구현에는 다음 기능이 있습니다.

- 리스트 만들기·선택·이름 변경·순서 변경·삭제
- 문장 추가·수정·순서 교환·삭제와 현재 리스트의 문장 전체 삭제
- 페이지에서 선택한 텍스트를 번호 위치에 저장
- 번호 위치의 문장을 클립보드에 복사
- 단축키 성공·오류 결과를 웹 알림으로 표시
- Chrome 프로필의 로컬 확장 저장소에 데이터 보관

총 저장 항목은 최대 100개입니다. 리스트 10개 × 리스트당 문장 10개이며, 저장 공간 한도도 적용됩니다. 문장 자체의 별도 글자 수 제한은 두지 않습니다.

다음 기능은 제품 범위에 없습니다.

- 로그인, 서버 저장, Chrome Sync, 기기 간 동기화, 공유·협업
- 이미지·파일·HTML 서식 저장
- 기존 클립보드 읽기, 클립보드 기록 수집, 자동 붙여넣기
- 문장 검색, 태그, 폴더, 즐겨찾기
- 내보내기·가져오기, 변경 이력, 휴지통, 백업·복구
- 비밀번호 보관, 광고, 사용 분석, 원격 오류 수집

## 처음 사용하는 순서

1. C:V 아이콘을 눌러 팝업을 엽니다.
2. 리스트가 없으면 리스트 추가 동작으로 이름을 입력합니다. 리스트 관리 화면에서도 추가할 수 있습니다.
3. 만든 리스트를 현재 리스트로 선택합니다. 생성과 선택은 별도 동작입니다.
4. 문장 목록 아래쪽의 추가 버튼으로 자주 쓰는 텍스트를 저장합니다.
5. 일반 웹 페이지의 입력창 밖에서 `Alt+1`을 누릅니다. Mac에서는 `Option+1`입니다.
6. 복사 성공 알림을 확인하고, 입력할 곳을 클릭한 뒤 `Ctrl+V` 또는 `Command+V`로 붙여넣습니다.

복사만으로 입력창에 내용이 들어가지는 않습니다. 기존 클립보드 내용은 새로 복사한 문장으로 바뀝니다.

## 단축키

숫자 `1`~`9`는 1~9번, `0`은 10번입니다. 현재 구현은 키보드 위쪽 숫자 키와 숫자 키패드의 키 코드를 처리합니다.

| 동작 | Windows/Linux | macOS | 결과 |
| --- | --- | --- | --- |
| 팝업 열기 | `Ctrl+B` | `Command+B` | Chrome이 C:V 팝업 열기를 처리 |
| 리스트 선택 | `Shift+숫자` | `Shift+숫자` | 해당 순서의 리스트를 현재 리스트로 저장 |
| 문장 복사 | `Alt+숫자` | `Option+숫자` | 현재 리스트의 해당 문장을 클립보드에 기록 |
| 선택 텍스트 저장 | `Shift+Alt+숫자` | `Shift+Option+숫자` | 현재 리스트의 해당 위치에 선택한 텍스트 저장 |
| 붙여넣기 | `Ctrl+V` | `Command+V` | 운영체제·대상 앱의 기능. C:V가 자동 실행하지 않음 |

팝업 열기는 Chrome에 제안한 기본 키이며 실제 할당은 충돌이나 사용자 설정에 따라 달라질 수 있습니다. `chrome://extensions/shortcuts`에서 확인합니다. 나머지 숫자 단축키는 웹 페이지 코드가 처리하며 이 설정에서 개별 변경할 수 없습니다.

### 입력창과 페이지 제한

- 리스트 선택과 문장 복사는 `input`, `textarea`, 편집 가능한 영역 안에서 실행하지 않습니다. 입력창 밖에 초점을 두고 사용합니다.
- 선택 텍스트 저장은 입력창에서도 처리합니다. 비밀번호 입력 필드의 선택 텍스트는 읽지 않습니다.
- 공백뿐인 선택이나 선택 영역이 없으면 저장하지 않습니다.
- 키를 누르고 있는 동안의 반복 이벤트, 한글 등 입력 조합 중 이벤트, `Ctrl`·`Command`·`AltGraph`가 추가된 조합은 무시합니다.
- 웹 단축키는 HTTP/HTTPS 페이지의 최상위 프레임에서 동작하도록 작성돼 있습니다. iframe 내부, `chrome://`, Chrome Web Store 등 실행이 제한되는 페이지를 지원한다고 가정하지 않습니다.
- Chrome의 사이트 접근 제한, 페이지 단축키 충돌, 클립보드 접근 실패 때문에 실행되지 않을 수 있습니다.

지원 목표는 최신 안정 Chrome 데스크톱이며 macOS를 우선 검증 환경으로 삼습니다. Windows/Linux는 호환 대상이나 이번에 검증하지 않았습니다. Firefox, Safari, 모바일 Chrome은 지원 범위 밖입니다.

## 저장과 순서의 규칙

### 리스트

| 항목 | 규칙 |
| --- | --- |
| 개수 | 최대 10개 |
| 이름 | 앞뒤 공백을 제거한 뒤 1~100자. 빈 이름은 거부 |
| 중복 | 앞뒤 공백을 제거한 이름이 같으면 거부. 대소문자는 구분 |
| 이름 변경 | 현재 이름 그대로 저장하면 변경 없음 |
| 순서 변경 | 옮긴 리스트를 대상 위치에 삽입하고 나머지를 밀어 순서를 정함 |
| 삭제 | 해당 리스트와 안의 문장을 함께 삭제 |
| 현재 리스트 삭제 | 선택을 해제. 다른 리스트를 자동 선택하지 않음 |

현재 리스트는 없거나 하나입니다. 현재 리스트가 없으면 문장 저장·복사를 하지 않습니다. 리스트 이름과 순서를 바꿔도 현재 선택은 ID로 유지됩니다.

이름 길이는 코드에서 JavaScript 문자열 길이로 계산합니다. 한글·영문은 대체로 한 글자에 1이지만 일부 이모지는 2 이상이므로 화면상 100글자보다 먼저 제한될 수 있습니다.

### 문장

| 항목 | 규칙 |
| --- | --- |
| 개수 | 리스트당 최대 10개. 번호 사이에 빈칸이 없음 |
| 내용 | 일반 텍스트와 줄바꿈. 공백뿐인 값은 거부 |
| 원문 | 유효한 입력의 앞뒤 공백과 줄바꿈은 보존 |
| 중복 | 같은 리스트의 다른 문장과 전체 텍스트가 같으면 거부. 다른 리스트에는 같은 텍스트를 저장할 수 있음 |
| 팝업에서 추가 | 목록 맨 뒤에 추가 |
| 같은 값으로 수정 | 변경 없음 |
| 순서 변경 | 출발 문장과 대상 문장의 위치만 서로 교환 |
| 삭제 | 뒤 문장을 당겨 빈 번호 없이 정렬 |
| 전체 삭제 | 현재 리스트의 문장만 삭제. 리스트와 다른 리스트의 문장은 유지 |

예를 들어 `A, B, C, D`에서 1번을 3번으로 끌면 리스트는 `B, C, A, D`, 문장은 `C, B, A, D`가 됩니다. 같은 위치나 유효하지 않은 대상에서는 순서를 바꾸지 않습니다.

### 선택한 텍스트를 저장할 때

단축키를 누른 순간의 선택 내용만 읽습니다. 같은 번호에 이미 문장이 있으면 **확인 대화상자 없이 교체**합니다. 되돌리기 기능은 없습니다.

| 현재 문장 수가 3개일 때 | 결과 |
| --- | --- |
| 1~3번에 저장 | 해당 위치의 문장을 교체 |
| 4번에 저장 | 마지막에 새 문장을 추가 |
| 5~10번에 저장 | 아무것도 바꾸지 않음. 빈 위치를 만들지 않음 |

중복이나 저장 오류가 발생하면 기존 내용이 유지되도록 처리합니다. 위치가 없거나 현재 리스트가 없는 경우에는 성공 알림도 표시하지 않습니다.

## 관리 화면과 피드백

- 상단 리스트 선택 메뉴에서 현재 리스트를 바꿉니다. 같은 메뉴의 ‘문장 전체 삭제’는 현재 리스트에만 적용됩니다.
- 리스트 관리 화면에서 리스트를 추가하거나 순서를 바꿉니다. 리스트의 더보기 메뉴에는 이름 변경과 삭제가 있습니다.
- 문장 더보기 메뉴에서 수정·삭제합니다. 긴 문장은 목록에서 일부만 보이고 편집 화면에서 원문을 확인합니다.
- 삭제 확인에는 대상과 영향을 표시합니다. 취소하면 데이터가 유지됩니다.
- 조회 중, 데이터 없음, 조회 실패를 구분합니다. 조회 실패에는 다시 시도하는 동작을 제공합니다.
- 저장 성공 응답을 받은 뒤 목록과 선택을 확정합니다. 실패하면 초안과 기존 화면 데이터를 유지합니다.
- 응답이 유실되면 같은 변경을 바로 재전송하지 않고 ‘저장 결과 확인’ 또는 ‘다시 불러오기’로 실제 저장 결과부터 확인합니다.
- 팝업을 닫으면 저장하지 않은 초안은 사라집니다. 이미 background에 전달된 요청은 닫기 동작으로 취소되지 않으므로 다시 열어 저장 결과를 확인합니다.

### 웹 알림

현재 구현은 성공 알림을 **1.5초**, 오류 알림을 **5초** 동안 표시합니다. 이전 문서의 성공 알림 2.5초 설명을 현재 구현에 맞췄습니다.

| 상황 | 표시 내용 |
| --- | --- |
| 리스트 선택 성공 | ‘리스트 변경’과 리스트 이름 |
| 복사·저장 성공 | 리스트 이름과 ‘복사됨’ 또는 ‘저장됨’, 문장 미리보기 |
| 연결 실패 | ‘C:V에 연결하지 못했습니다.’와 페이지 새로고침 안내 |
| 저장·복사 실패 | 실패 원인과 다음 행동 |
| 없는 번호, 현재 리스트 없음, 빈 선택 | 알림 없이 작업하지 않음 |

미리보기는 연속 공백과 줄바꿈을 공백 하나로 줄이고 앞뒤 공백을 제거한 뒤 최대 60개 UTF-16 코드 단위로 자릅니다. 대부분의 한글·영문은 60자에 해당하지만 일부 이모지는 중간에서 잘릴 수 있습니다. 이 처리는 저장된 원문을 바꾸지 않습니다. 현재 성공 알림에는 문장 번호가 없습니다.

알림은 페이지 아래 중앙에 표시되고 클릭이나 입력을 막지 않습니다. 새 결과가 오면 이전 알림을 교체하며, 모션 감소 설정에서는 이동 애니메이션을 사용하지 않습니다.

## 오류와 데이터 보존

| --- | --- |

| 알 수 없는 저장 형식 | 오류로 처리. 자동 삭제·마이그레이션하지 않음 |
| 다른 창에서 리스트 정보 변경 | 오래된 이름·순서·삭제 요청을 거부하고 최신 목록 확인 안내 |
| 클립보드 쓰기 실패 | 복사 성공으로 표시하지 않음. 활성 페이지와 권한 확인 |

리스트 정보 변경은 최신 저장 내용에 반영하므로 그 사이 추가된 문장을 전체 스냅샷으로 덮어쓰지 않습니다. 모든 종류의 동시 편집에 충돌 해결 UI가 있는 것은 아닙니다. 세부 계약은 [아키텍처](architecture.md)를 참고합니다.

## 데이터와 개인정보 요약

C:V는 `chrome.storage.local`에 리스트, 문장, 현재 선택을 저장합니다. 서버 전송과 기기 간 동기화는 없으며, C:V 자체 암호화도 없습니다. 비밀번호·인증 토큰·민감한 고객 정보 보관용으로 사용하지 않습니다.

확장 제거 또는 저장 데이터 삭제 시 내용을 잃을 수 있습니다. 자체 백업·휴지통·복구와 이전 JavaScript 버전의 IndexedDB 데이터 이전 기능은 없습니다. 문장·리스트 삭제 범위는 위의 저장 규칙을 따릅니다. C:V에서 원문을 삭제해도 이미 복사한 클립보드나 다른 앱의 사본까지 지우지는 않습니다. 권한과 저장 형식은 [아키텍처](architecture.md)에 설명합니다.

## 구현상 제한과 남은 검증

- 순서 변경은 드래그와 키보드로 제공합니다. 핸들에서 Space로 잡고 방향키로 대상을 정한 뒤 Space로 놓으며 Escape로 취소합니다. 별도의 위·아래 이동 메뉴는 없습니다.
- 입력창의 선택 텍스트 저장 조합에서는 원문이 기호로 바뀌지 않도록 응답 전에 기본 키 동작을 막습니다. 저장 실패·없는 위치에서도 기본 입력은 막힐 수 있습니다.
- 성공 알림은 1.5초이며 문장 번호를 표시하지 않습니다. 과거 요구사항의 2.5초·번호 포함 설명과 구분합니다.
- 저장 실패·동시 변경·재시작 검증은 [QA 절차](qa.md)의 기록과 범위를 확인합니다. 현재 저장소에 이를 반복 실행할 영구 자동 테스트는 없습니다.
- 접근성 속성과 키보드 동작의 구현만으로 모든 보조 기술 지원을 보장하지 않습니다. 미검증 환경은 QA 기록에 남깁니다.

출시 판정에는 현재 제출할 빌드의 핵심 흐름, 데이터·권한, 남은 검증 항목과 공개 개인정보 안내 확인이 필요합니다. 코드와 스토어 자료가 존재한다는 사실만으로 공개 배포 완료를 주장하지 않습니다.
