# 기능 명세

## 팝업 UI 기능

### 리스트 관리

- 리스트 추가
- 리스트 이름 수정
- 리스트 순서 변경
- 리스트 삭제
- 현재 리스트 선택

제한 사항:

- 최대 10개의 리스트를 저장할 수 있습니다.
- 같은 이름의 리스트는 중복 저장할 수 없습니다.

### 커맨드 관리

- 현재 리스트의 커맨드 조회
- 커맨드 추가
- 커맨드 내용 수정
- 커맨드 삭제
- 커맨드 순서 변경
- 현재 리스트의 커맨드 전체 삭제

제한 사항:

- 리스트당 최대 10개의 커맨드를 저장할 수 있습니다.
- 같은 리스트 안에서 같은 커맨드 텍스트는 중복 저장할 수 없습니다.

## 단축키 기능

### 팝업 열기

- Windows: `Ctrl + B`
- macOS: `Command + B`

### 현재 리스트 선택

- `Shift + 1`부터 `Shift + 9`: 1번째부터 9번째 리스트 선택
- `Shift + 0`: 10번째 리스트 선택

### 커맨드 클립보드 복사

- `Alt + 1`부터 `Alt + 9`: 현재 리스트의 1번째부터 9번째 커맨드 복사
- `Alt + 0`: 현재 리스트의 10번째 커맨드 복사

### 선택 텍스트를 커맨드로 저장

- 웹 페이지에서 텍스트를 선택합니다.
- `Shift + Alt + 1`부터 `Shift + Alt + 9`: 현재 리스트의 1번째부터 9번째 위치에 저장
- `Shift + Alt + 0`: 현재 리스트의 10번째 위치에 저장

## 사용 흐름 예시

1. 확장 프로그램 팝업을 엽니다.
2. 리스트를 생성합니다.
3. 웹 페이지에서 `Shift + 숫자`로 현재 리스트를 선택합니다.
4. 저장하고 싶은 텍스트를 드래그해 선택합니다.
5. `Shift + Alt + 숫자`로 선택 텍스트를 커맨드에 저장합니다.
6. 이후 `Alt + 숫자`로 원하는 커맨드를 클립보드에 복사합니다.
7. 입력창에서 `Ctrl + V` 또는 `Command + V`로 붙여넣습니다.

## 데이터 보존

리스트와 커맨드는 IndexedDB에 저장됩니다. 브라우저의 사이트 데이터, 캐시, 확장 프로그램 데이터를 삭제하면 저장된 데이터가 사라질 수 있습니다.

개인정보, 비밀번호, 인증 토큰, 민감한 고객 정보처럼 유출 위험이 큰 값은 저장하지 않는 것이 좋습니다.
