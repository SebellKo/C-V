# C:V 기능 문서

`C:V`의 주요 기능을 기능 단위로 나눠 정리한 문서 모음입니다.

## 문서 목록

- `list-management.md`: 리스트 생성, 선택, 이름 수정, 삭제, 순서 변경
- `command-management.md`: 커맨드 추가, 수정, 삭제, 전체 삭제
- `shortcut-copy-paste.md`: 단축키 기반 리스트 선택, 슬롯 저장, 클립보드 복사
- `drag-and-drop-ordering.md`: 리스트/커맨드 정렬 방식과 저장 시점
- `persistence.md`: IndexedDB 저장 구조와 메시지 기반 데이터 흐름
