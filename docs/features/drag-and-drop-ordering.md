# 드래그 앤 드롭 정렬

## 기능 목적

드래그 앤 드롭 정렬은 리스트와 커맨드의 순서를 빠르게 바꾸기 위한 기능입니다.
숫자 슬롯 기반 제품 특성상 순서는 단순 표시 순서가 아니라 "실제 선택 인덱스"와 연결됩니다.

## 정렬이 적용되는 대상

- 리스트 정렬
- 커맨드 정렬

## 리스트 정렬

리스트 정렬은 `Edit` 모달 안에서 수행합니다.
사용자는 리스트 항목 왼쪽의 드래그 핸들을 잡고 순서를 바꿀 수 있습니다.

이 변경은 즉시 영구 저장되지 않습니다.
편집 모달 안의 임시 상태에만 반영되고, 마지막에 `확인` 버튼을 눌러야 저장됩니다.

### 리스트 정렬 저장 시점

1. 사용자가 편집 모달에서 순서를 바꾼다.
2. 로컬 상태의 리스트 배열 순서가 바뀐다.
3. `확인` 버튼을 누르면 수정된 전체 리스트 배열이 저장된다.

## 커맨드 정렬

커맨드 정렬은 메인 화면의 커맨드 목록에서 수행합니다.
각 커맨드 카드 상단의 드래그 아이콘으로 위치를 바꿀 수 있습니다.

커맨드 정렬은 드래그가 끝나는 시점에 바로 저장 요청이 발생합니다.
동시에 화면의 로컬 상태도 즉시 갱신됩니다.

### 커맨드 정렬 저장 시점

1. 사용자가 커맨드를 드래그한다.
2. 드롭 위치가 확정되면 배열 순서를 계산한다.
3. 바로 저장 mutation을 호출한다.
4. 화면 목록도 같은 순서로 즉시 갱신된다.

## 왜 중요한가

이 프로젝트는 숫자 기반 슬롯 선택을 사용합니다.
따라서 정렬은 단순 UI 정리 기능이 아니라, 실제 단축키 매핑 순서를 조정하는 의미를 가집니다.

예를 들어 커맨드를 첫 번째 위치로 옮기면 이후 `Alt + 1` 대상이 달라질 수 있습니다.

## 현재 구현 기준 메모

- 리스트와 커맨드 모두 `dnd-kit`을 사용합니다.
- 리스트 정렬은 편집 모달 내 배치 수정 방식입니다.
- 커맨드 정렬은 드래그 종료 즉시 저장되는 방식입니다.
- 리스트 정렬 후 저장은 `list` 스토어를 다시 쓰는 구조이고, 커맨드 정렬은 특정 리스트의 `commands` 배열만 교체합니다.
