# 디자인 변경 검증 · 2026-10-17

## 범위와 환경

승인된 HTML/CSS 와이어프레임을 실제 React popup과 콘텐츠 알림에 반영했습니다. 기존 단축키 조합, 저장 schema와 manifest 권한은 변경하지 않습니다.

로컬 브라우저 검증은 실제 Popup 컴포넌트와 Background dispatcher/state 규칙을 실행하고 Chrome runtime/storage 경계만 메모리 대역으로 교체했습니다. 제품 코드에 QA 데이터나 계측 코드를 넣지 않았습니다.

## 확인 결과

- Popup 300×380, Header/Footer 각 52px, 내부 스크롤과 가로 넘침 없음.
- 리스트 생성·선택·이름 변경, 빈 상태, 10개 제한과 1~9/0 번호 표시.
- 리스트 메뉴는 이름 변경·삭제, 커맨드 메뉴는 내용 수정·삭제만 표시.
- 리스트 키보드 DnD 삽입과 현재 ID 유지, 커맨드 키보드·포인터 DnD 교환과 포커스 복원.
- 문장 수정과 공백 입력 검증, 저장되는 앞뒤 공백·줄바꿈 원문 유지.
- 리스트 선택 메뉴의 문장 전체 삭제: 취소 시 데이터 유지, 확인 시 현재 리스트만 비움, 메뉴 trigger로 포커스 복원.
- 저장·조회 실패 후 오류 표시와 재시도, 수정 초안·기존 데이터 유지.
- 선택 저장 응답을 보류해도 Command 목록 top=52px와 버튼 밝기를 유지하고 skeleton·배치를 밀어내는 진행 배너를 표시하지 않음.
- 선택 메뉴 항목 간 4px 간격, 선택 배경과 키보드 강조 배경 구분. 메뉴 버튼 열린 상태 배경 확인.
- 실제 toast 모듈의 페이드인·페이드아웃 및 연속 호출 교체 확인. 최종 표시 시간 1.5초, 복사·저장 결과와 미리보기는 별도 줄로 표시.
- 빌드된 콘텐츠 스크립트의 단축키 경로를 API 경계 대역으로 실행해 복사 원문 보존과 두 줄 알림을 확인. 미리보기 최대 60자 제한 유지.
- TypeScript 및 production build, git diff --check, ZIP 압축 무결성·manifest/asset 경로·권한·QA 데이터 미포함 확인.

## 남은 확인

설치된 일반 Chrome의 확장 갱신과 실제 popup/OS 클립보드/웹 단축키, 마우스를 올렸을 때의 hover, OS 모션 감소 설정을 켠 최종 빌드 검증은 남아 있습니다. 영구 회귀 테스트와 전체 출시 QA 완료를 의미하지 않습니다.

빌드 ZIP과 스크린샷은 Git에 포함하지 않는 로컬 release 산출물입니다.
