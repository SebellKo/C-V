오류 주입은 테스트 브라우저의 API만 임시 변경했습니다. Chrome API receiver를 보존해 호출하고 검증 종료 시 복원했습니다. 마지막에는 확장 자체를 새로고침해 새 실행 context에서도 동작을 확인했습니다. production source와 dependency는 수정하지 않았습니다.

Popup 종료 검증은 저장 gate가 대기 중임을 확인하고, 원문이 아직 storage에 없는 상태에서 native window가 popup이 아닌 일반 browser window로 바뀐 것을 확인했습니다. 이후 gate를 해제하자 전달된 요청이 완료되고 새 view에서 결과를 조회할 수 있었습니다. 시간 지연만으로 종료 시점을 추정하지 않았습니다.

확장 화면의 axe 4.12.1 검사에서 위반은 0건, 수동 판정이 필요한 incomplete는 1건이었습니다. axe 결과는 VoiceOver 수동 검증을 대신하지 않습니다. 초기 locator·비동기 렌더 시점·Chrome API receiver 문제는 임시 harness 오류로 분류하고 실제 UI·pointer·API에서 재검증했습니다.
