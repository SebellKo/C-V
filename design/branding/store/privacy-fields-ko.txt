storage 권한 사용 사유

사용자가 만든 리스트 이름, 저장 문장, 순서와 현재 선택한 리스트를 Chrome 프로필의 로컬 확장 저장소(chrome.storage.local)에 보관하기 위해 필요합니다. 브라우저를 다시 실행해도 저장한 문장을 계속 사용할 수 있게 하며, 외부 서버 전송이나 기기 간 동기화에는 사용하지 않습니다.

clipboardWrite 권한 사용 사유

사용자가 복사 단축키(Alt/Option + 숫자)를 실행했을 때 해당 위치의 저장 문장을 시스템 클립보드에 쓰기 위해 필요합니다. 이후 사용자가 원하는 곳에 직접 붙여넣을 수 있습니다. 기존 클립보드 내용은 읽거나 수집하지 않습니다.

사이트 접근 사용 사유

HTTP/HTTPS 웹 페이지에서 C:V 단축키를 처리하고, 저장 단축키를 누른 시점에 사용자가 선택한 텍스트를 저장하며, 동작 결과를 알림으로 보여주기 위해 필요합니다. 방문 기록, 페이지 URL, 전체 본문이나 일반 키 입력은 저장하지 않습니다.
